# DDS Tweak v0.1.0

[简体中文](#简体中文) · [English](#english)

## 简体中文

DDS Tweak 是面向 Minecraft Fabric 客户端的操作与界面增强模组。v0.1.0 是继 0.1.0-beta.1 后的正式版本候选。

### 新增与改进
- 提供 **21 个 Minecraft 构建目标（1.14.4–26.3）**，针对不同版本限制不适用的功能及 Mixin；各版本的可用功能并不完全相同。
- 增强客户端操作与界面，包括静默自动进食、物品栏交互、相机/玩家选择与快捷配置等功能。
- 在支持的 Minecraft 版本上提供寻路指示栏头像（Locator Heads）、方块声音追踪、积雪覆盖等可视化调整。
- 改进可选的 **Carpet DDS Addition** 客户端联动，包括假人/背包界面及撤销、重做快捷键；实际操作仍由兼容的服务端功能与权限决定。
- 将客户端配置集中于 `config/dds-tweak/`，保留旧配置文件以便回退；支持通过 MaLiLib 快捷键或可选的 Mod Menu 进入设置。

### 修复与兼容性
- 修复多版本功能注册、物品选择器与背包交互等兼容性问题。
- 完善游戏版本相关的依赖声明、构建产物检查及第三方许可说明。

### 安装须知
- 安装与目标 Minecraft 版本匹配的 **Fabric Loader、Fabric API、MaLiLib** 和 DDS Tweak JAR。
- **Carpet DDS Addition 不是独立使用客户端功能的必需依赖**；部分联动功能需要服务端提供对应能力。
- 具体功能及最低 Minecraft 版本参见 [版本能力说明](../VERSION_CAPABILITY_BOUNDARIES.md)。切换旧版前请备份客户端配置。

## English

DDS Tweak is a client-side Fabric mod for practical Minecraft controls and UI enhancements. v0.1.0 is the formal release candidate following 0.1.0-beta.1.

### Added & improved
- **21 Minecraft build targets (1.14.4–26.3)** with version-specific feature and Mixin boundaries. Not every feature is available on every version.
- Client controls and interfaces, including silent auto-eating, inventory interactions, camera/player selection, and configurable shortcuts.
- Visual tweaks such as Locator Heads, block sound tracking, and better snow coverage on supported Minecraft versions.
- Optional **Carpet DDS Addition** client integration, including fake-player/inventory UI and configurable Undo/Redo shortcuts. Compatible server capabilities and permissions remain authoritative.
- Local client configuration under `config/dds-tweak/`, preserving legacy files for rollback, with MaLiLib shortcuts and optional Mod Menu access.

### Fixes & compatibility
- Addressed cross-version feature registration, item picker, and inventory-interaction compatibility issues.
- Improved version-specific dependency metadata, release artifact checks, and third-party license notices.

### Installation notes
- Install the matching **Fabric Loader, Fabric API, MaLiLib**, and DDS Tweak JAR for your Minecraft version.
- **Carpet DDS Addition is optional** for standalone client features; some integrations require server-side support.
- See [Version capability boundaries](../VERSION_CAPABILITY_BOUNDARIES.md) for feature availability. Back up client settings before downgrading.
