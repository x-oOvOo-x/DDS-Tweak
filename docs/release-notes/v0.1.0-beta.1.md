# DDS Tweak 0.1.0-beta.1

First release candidate for **Minecraft 1.21.11 / Fabric**.

### Included
- Client-side visual, interface, hotkey, and gameplay quality-of-life tweaks.
- Optional UI integration with Carpet DDS Addition when compatible server capabilities are available.
- An optional built-in CozyUI+ adaptation for the fake-player interface (off by default).

### Changed for Beta
- Removed the Happy Ghast riding speed feature from **this Beta branch only**, including its mixins, settings, translations and tests.
- Kept the development `main` branch unchanged.
- Added release license/attribution files and corrected the Fabric metadata so it does not advertise an inaccessible private development source URL.

### Requirements
- **Minecraft:** 1.21.11
- **Mod loader:** Fabric Loader, 0.14.25 or newer
- **Required:** Fabric API 0.141.3+1.21.11 or newer compatible build; MaLiLib 0.27.20 or newer compatible build
- **Java:** 21 or newer
- **Optional:** Carpet DDS Addition and other compatible client integrations

### Verification and release status
- Full CI `buildAndGather` succeeded for the Beta branch.
- The project owner reports that an in-game test passed; the exact scenario matrix was not recorded.
- This is a **Beta**, not a statement that every optional integration has been verified.
- Review licenses, redistribution source availability, and AI/derivative-content disclosures before Modrinth publication.
