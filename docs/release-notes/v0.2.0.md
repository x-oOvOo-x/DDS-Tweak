# DDS Tweak v0.2.0

### ✨ 新增与优化 / Added & Improved

- 新增 Carpet 规则管理器，支持规则搜索、筛选、收藏、分组、配置方案与操作历史，默认按 **F7** 打开。(Added a Carpet rule manager with search, filters, favorites, groups, presets and operation history; **F7** opens it by default.)
- 将原版游戏规则集成到规则管理界面；旧版远程服务器的规则读取需要支持对应能力的 Carpet DDS Addition，修改仍受服务端权限控制。(Integrated vanilla gamerules into the rule manager; older remote servers require a compatible Carpet DDS Addition for rule snapshots, and changes remain subject to server permissions.)
- 将支持能力协商的假人背包与末影箱扩展交互适配至 Minecraft **1.19.4+**，并保留高版本既有行为。(Extended supported fake-player inventory and Ender Chest interactions to Minecraft **1.19.4+**, retaining existing behavior on newer versions.)

### 🐛 修复 / Fixed

- 修正原始配置名称的显示优先级。(Fixed original configuration name display priority when used with MasaGadget or TweakerMore.)
- 限制无响应服务端上的 DDS 握手自动重试，避免持续发送探测包。(Bound DDS handshake retries on unresponsive servers to prevent repeated probes.)
